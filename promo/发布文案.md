# 内容简介（长版，适合论坛 / 贴吧 / B 站专栏）

**NEON SATURN 简体中文汉化版** 来了！

NEON SATURN 是开源世嘉土星（Sega Saturn）模拟器 Ymir 的安卓移植版。模拟核心沿用 Ymir 原版，在手机上配了一套原生界面：设置向导、封面游戏库、土星风格的触屏按键和游戏内快捷菜单。

这次汉化不只改了外层界面，模拟器底层（C++）传给界面的提示也一起翻译成了中文。界面固定显示中文，跟手机系统语言无关。

**主要特色**
- 🀄 **界面全中文**：设置向导、游戏库、设置、快捷菜单、即时存档、触屏按键编辑器、成就、关于页面都已汉化
- 🎮 **画面**：可选软件渲染器（最精确），或 Vulkan GPU 渲染器，最高 8 倍内部分辨率；支持 6 倍 xBRZ 放大滤镜、去隔行和半透明网格
- 💾 **即时存档 / 读档**：多个存档位，带画面预览
- ⏪ **倒带**：一键回退最近几秒（默认关闭，可在设置中开启）
- 🖼️ **封面游戏库**：列表、美版盒装、日版 CD 盒三种视图，带封面流动效果，封面自动下载
- 👆 **触屏按键**：土星风格虚拟按键，可自由拖动和缩放，横屏、竖屏分别保存布局
- 🕹️ **手柄 / 键盘**：通过 SDL 支持实体手柄，内置手柄映射数据库
- 🏆 **RetroAchievements 成就**：登录后可在游戏中获得成就
- 💳 **扩展卡带**：自动为《拳皇 96/97》《合金弹头》《恶魔战士 救世主》等游戏插入所需的内存扩展卡

**运行要求**
- 安卓 9（API 28）或以上
- 64 位 ARM 设备（arm64-v8a）
- 需要自行准备世嘉土星 BIOS 文件和游戏镜像（支持 CHD / CUE / ISO / CCD / MDS）

**使用方法**
1. 安装 APK
2. 按设置向导导入 BIOS（可导入多个地区版本）
3. 选择存放游戏的文件夹，游戏库会自动出现
4. 点击游戏即可开始

**说明**
- 本软件开源免费，以 GPL-3.0 许可证发布，**不包含任何 BIOS 或游戏文件**，请使用自己合法拥有的游戏
- 游戏本身的文字，以及 RetroAchievements 服务器返回的成就名称和描述，不在汉化范围内
- 原作：Ymir（作者 StrikerX3），安卓移植：NEON SATURN（作者 izzy2lost），本版为简体中文汉化版
